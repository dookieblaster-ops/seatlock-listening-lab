# Agent instructions

The specification and the working rules for this repository are in `README.md`. Read it in full before your first change in a session, then read `STATUS.md` for the current state and the next steps. README section 1 applies to every session.

Then read `COMS.md`. Its newest handoff, at the top of the active thread, says what to do next (README section 1.4).
